必读｜第一次安装前请花 30 秒看完这张卡
================================================

【双击「安装.command」时弹出「无法验证 / 可能源包含恶意软件」？】
这是 macOS 对所有未签名脚本的统一安全拦截，不是病毒警告。
处理方法（一次即可，以后不会再拦）：

  1. 弹窗上点「完成」（不要点移到废纸篓）
  2. 打开  系统设置 → 隐私与安全性
  3. 拉到页面最底部，找到关于「安装.command」的提示，点「仍要打开」（可能要求输入开机密码）
  4. 回到文件夹，再双击一次「安装.command」

不想动安全设置？用终端方式（效果完全相同）：
  打开「终端」，把下面的命令拖进去回车（注意 cd 后面是你的实际解压路径）：
      cd "把完整版文件夹拖到这里" && bash ats-status/scripts/install.sh

【安装过程会发生什么】
  · 检查 Node.js / Chrome 环境（缺什么会提示装什么）
  · 下载安装依赖（仅安装这一次需要联网）
  · 注册开机自启服务和工作日 9:30 / 14:30 / 20:00 的定时任务
  · 自动打开台账页面 http://127.0.0.1:7788/

【装完之后】
  1. 台账页面收藏到书签，日常就用它
  2. 「自动跟进」→「去接入」扫码登录你投过的公司（每家一次）
  3. 控制台「邮件与推送」配置邮箱授权码，面试邀约自动进台账
  4. 详细玩法见台账里的「使用指南」

【卸载】
  见文件夹内「安装说明.md」末尾的卸载命令，两条 launchctl + 两行 rm，无残留。
