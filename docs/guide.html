01它是什么

一句话：你在台账里记投递、看进度；电脑上的控制台替你盯着各公司官网，进展自动回填，拿不准的来问你。

台账（日常用的页面）：记录每一条投递、管理岗位库、看阶段分布和面试安排。所有数据只存在你自己的浏览器里，不上传任何服务器。

控制台（背后的助手）：登录过哪家公司官网，它就能低频、克制地读取那家的「我的投递」，把最新状态带回台账；笔试/面试邀约邮件也会帮你盯着。你平时不需要打开它。

三句话记住：接入公司 → 状态自动更新 → 拿不准的进展请你拍板。

02第一次使用（约 15 分钟，做完一次就不用管）

上手清单 0 / 4

关于「一键收录插件」（可选）

「同步腾讯文档」和「识别投递网址」两个功能需要一个浏览器插件帮你在已登录的腾讯文档里读取岗位。在台账里点同步时，会弹出安装指引，照着做即可。不装插件也完全能用：岗位可以手动「新增投递」，或在同步弹窗里用「粘贴表格内容导入」。

关于接入公司

接入 = 用你自己的账号扫码登录一次该公司招聘官网。之后控制台会像真人一样低频地帮你查看投递进展（每天两三次、深夜从不查询）。哪家没接入，那家就保持手动维护，随时可以补接。

03每天怎么用

打开台账，先看「今天要做的」四张卡，数字清零就可以安心去投新岗位。

卡片意思点它会发生什么
N 条进展需要你拍板官网进展和你的记录有出入，或发现你还没记录的投递打开拍板弹窗，一次一条，按提示选一下
七天内笔试 / 面试最近的安排（含邮件里识别到的）跳到投递列表去准备
N 家公司还没接入你投了但还没接官网的公司引导你扫码接入
N 条记录可以自动更新官网有这家的数据，但记录还没连上编辑记录，点选官网条目连上

记录「当前阶段」旁的小徽章告诉你这条的来源：

🔗 官网自动更新中　✎ 手动维护　🔗⚠ 官网已无此条（自动转手动，数据没丢，编辑里可重新绑定）

点「编辑」还能在弹窗里直接连接或更换官网条目：

想立刻看最新状态？「自动跟进」右上角点「现在刷新」。平时每天 9:30 / 14:30 / 20:00 自动更新，不用守着。

04自动跟进与拍板

「自动跟进」区块里是公司卡片的三种状态：

未接入 还没扫码——点「去接入」，弹出官网登录窗口，登录后回来点「我登录好了」。
待完成登录 登录窗口开着还没完成——回窗口扫码，再点「我登录好了」。
已连接 一切正常，显示上次更新时间和跟进的投递数。

拍板弹窗长什么样

一次只问一件事，两个选择，几秒搞定：

场景它会怎么问
官网说已结束，但你改过这条「官网显示这条已经已结束，而且是你自己改过的——听官网的吗？」→ 听官网的 / 保留我的
你标记结束的流程又有动静「恢复跟进吗？」→ 恢复跟进 / 保持结束
官网有你没记录的投递「记入台账吗？」→ 记入台账 / 不是我的
官网有条记录和你的很像「是你记录里的哪一条吗？」→ 点选对应记录
邮箱里发现面试/笔试邀约「是你哪条投递的安排？」→ 点选记录，时间自动填入
💡
拿不准就选「这条先不管」——它会被记住，不会反复来烦你。所有自动改动都能在「数据安全 → 恢复上一个快照」一键撤销。

05邮件邀约（面试笔试提醒的来路）

总览里的笔试/面试安排，一部分就是这么来的：控制台读取你邮箱里面试/笔试邀请类邮件，认出时间、轮次和会议地点，然后到台账问你「是你哪条投递的安排？」，点选确认后自动填入安排时间。

怎么配邮箱（控制台 → 邮件与推送）

  1. 去邮箱官网生成「授权码」163：设置 → POP3/SMTP/IMAP → 开启服务并生成授权码；QQ 邮箱：设置 → 账户 → 开启 IMAP/SMTP → 生成授权码；Gmail：开启两步验证后生成应用专用密码。授权码不是登录密码。
  2. 在控制台填入选服务商 → 填邮箱地址和授权码 → 保存。可以添加多个邮箱，每轮会全部检查。
  3. 点「测试连接」验证提示连接成功即可。之后每天三次自动检查，也可以在「邮件通知」卡点「立即拉取」。
✓
邮件只在你的电脑上读取，不会上传；识别不出时间的邀约不会乱写安排——宁缺毋滥。

06数据与备份

你的投递记录只存在这台电脑的这台浏览器里。台账已经有两层保护（实时保存 + 最近 25 个历史快照），建议再加一道保险：

  1. 设置自动备份文件（推荐，1 分钟）「数据安全 → 设置自动备份文件」，选一个位置（比如移动硬盘或网盘同步文件夹）。之后每次改动自动写一份进去。
  2. 改错了？一键回滚「数据安全 → 恢复上一个快照」，会先自动下载当前数据的备份再恢复。
  3. 换电脑 / 换浏览器旧设备「导出数据」→ 新设备「导入备份文件」。导入前系统还会再自动备份一次，不怕手滑。
⚠️
两个标签页同时开台账时，一边保存另一边会收到提示——按提示刷新即可，避免互相覆盖。导出的备份文件等于全部投递记录，别发给别人。

07手机上用

台账可以像 App 一样装到手机桌面（需要先通过电脑访问的地址在手机浏览器打开；同一局域网内用电脑的 IP 地址即可）：

iPhone / iPad（Safari）

打开页面 → 底部「分享」→「添加到主屏幕」→ 添加。

Android（Chrome）

右上角菜单 →「安装应用」或「添加到主屏幕」。

注意：自动跟进由你电脑上的控制台负责，手机上适合当「随身账本」——记录和查看都正常，只是不会自动更新官网状态。换手机前先「导出数据」。

08常见问题

为什么接入公司要我自己扫码？能全自动吗？
各大招聘系统的登录都靠扫码/短信验证，这是平台刻意的安全设计。工具选择「你人工登录一次，之后它像真人一样低频查看」——这是安全与自动化之间最稳妥的平衡。
某家公司显示「待完成登录」或状态很久没更新？
说明那家的登录过期了。在「自动跟进」找到该公司，点「去接入」重新扫码即可，其余公司不受影响。
官网状态和我自己记的不一样，听谁的？
工具不替你做主——弹拍板卡让你选。一般建议听官网的（官网更及时）；如果你有特殊判断（比如流程实际还在走），选「保留我的」，你的选择优先。
会不会把我的账号弄出问题？
工具严格按真人节奏工作：每家每天两三次页面访问、带随机间隔、深夜零查询。请不要手动调高查询频率；如果某家官网弹出验证码，就在控制台停用那家的自动查询，改为人工查看。
记录删错了 / 改错了怎么办？
「数据安全 → 恢复上一个快照」。最近 25 个版本都可以回，恢复前还会自动备份当前数据。
支持哪些公司？
美团、字节跳动、快手、携程、小红书、阿里巴巴开箱即用；投了这些公司，台账会自动出现对应卡片。其它公司正常手动记录，控制台里也可以添加新的官网（需要一点折腾，见「进阶」）。
使用一段时间后想彻底清理？
先「导出数据」留档。电脑上的控制台及其数据都在 ~/.ats-status 文件夹，整个删掉即可，无云端残留；浏览器里的台账数据清除该站点数据即可。

09进阶（大多数人不需要）

控制台是什么？我什么时候需要打开它？
地址是 http://127.0.0.1:7788/console/（或台账「设置 → 投递控制台」）。需要进去的场合：某家公司要重新接入、配置邮箱监控或飞书提醒、查看运行日志、添加新的招聘官网。日常记录和看进度完全不用进。
添加控制台没预置的公司官网
控制台「官网引擎」里可以编辑站点入口或新增自定义站点；接好后同样「登录接入 → 查询」。内置站点覆盖了常见的招聘系统（Moka、北森等），同系统的公司往往可以直接沿用。
飞书提醒（可选）
想要手机上收提醒：飞书建个群 → 群设置 → 群机器人 → 添加「自定义机器人」→ 复制 webhook 地址 → 控制台「邮件与推送」粘贴保存 → 点「发测试卡片」。webhook 地址等于往群里发消息的钥匙，不要发给任何人。
定时任务说明
官网状态检查由电脑的定时任务负责（工作日 9:30 / 14:30 / 20:00，随查询顺带检查邮箱）。它随控制台自动安装，无需手动配置；Mac 关机期间不查询也不丢数据，开机自动补上。
